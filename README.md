# ⚔️ Desconto Progressivo

## 🌸 Sobre o projeto

Este projeto foi desenvolvido em **Python** para simular um sistema de **desconto progressivo** de uma loja online.
O programa recebe o valor total da compra e calcula automaticamente o desconto e o valor final a ser pago.

## 🎴 Regras de desconto

| Valor da compra               | Desconto |
| ----------------------------- | -------: |
| 💮 Menor que R$ 200,00        |       5% |
| ⚔️ De R$ 200,00 até R$ 299,99 |      10% |
| ⭐ R$ 300,00 ou mais          |      15% |

## 🧙 Como funciona?

O usuário informa o valor total da compra.

O programa então:

1. 🔹 Identifica a faixa de valor da compra;
2. 🔹 Define o percentual de desconto;
3. 🔹 Calcula o valor do desconto;
4. 🔹 Calcula o valor final da compra;
5. 🔹 Exibe o resultado na tela.
